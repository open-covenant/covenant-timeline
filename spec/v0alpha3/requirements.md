# Requirements

| ID                  | Requirement                                                                                                 | Mechanical | Cases                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------------- | ---------- | ---------------------------------------------------------------------------------------------- |
| CTL3-CORE-001       | Integer coordinates, bounds, sequences, and cuts are within the safe-integer range.                         | no         | schema.event-unsafe-sequence                                                                   |
| CTL3-CORE-002       | Portable objects are closed discriminated unions and reject unknown core fields.                            | no         | schema.query-mixed-variants                                                                    |
| CTL3-CONTRACT-001   | A contract binds a subject to non-empty, uniquely identified temporal axes and contexts.                    | no         | schema.valid-contract,schema.contract-empty-axes                                               |
| CTL3-EVENT-001      | Events carry a schema, unique ID, and contiguous zero-based record sequence.                                | no         | schema.valid-constraint-event,schema.valid-coordinate-event                                    |
| CTL3-CONSTRAINT-001 | A difference constraint binds two same-context, same-axis points and declares at least one inclusive bound. | no         | schema.valid-constraint-event                                                                  |
| CTL3-ASSERTION-001  | Assertions, supersessions, and retractions retain evidence and refer only to earlier compatible records.    | no         | schema.valid-coordinate-event,schema.event-invalid-evidence-digest,schema.event-empty-evidence |
| CTL3-QUERY-001      | Every typed query pins a context and an explicit record-time knowledge cut.                                 | no         | schema.valid-point-query,schema.query-mixed-variants                                           |
| CTL3-CONCLUSION-001 | A conclusion binds a query-specific result to state, query, and semantic-result digests.                    | no         | schema.valid-relation-conclusion,schema.conclusion-bad-digest                                  |
| CTL3-PROOF-001      | A conclusion carries a proof receipt whose variant matches its semantic result.                             | no         | schema.valid-relation-conclusion,schema.conclusion-proof-mismatch                              |
| CTL3-PROJECT-001    | Projection isolates contexts and applies declarations, supersession, and retraction at the selected cut.    | no         |                                                                                                |
| CTL3-STN-001        | The reasoner computes consistency and tight difference bounds over the selected query component.            | no         |                                                                                                |
| CTL3-RELATION-001   | Point and interval queries enumerate all possible base relations without inferring causality.               | no         |                                                                                                |
| CTL3-VERIFY-001     | Proof verification checks bound bytes, result semantics, and the reasoner-specific witness independently.   | no         |                                                                                                |
| CTL3-COMPAT-001     | v0alpha1 and v0alpha2 validation and replay behavior remain unchanged.                                      | no         |                                                                                                |
