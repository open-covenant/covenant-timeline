# RFC 8785 fixtures

[`cases.json`](./cases.json) mirrors the compact input/output fixtures from the
JSON Canonicalization Scheme reference repository. They cover arrays, Unicode,
locale-independent property ordering, nested structures, and ECMAScript number
serialization.

The fixture source is
[`cyberphone/json-canonicalization`](https://github.com/cyberphone/json-canonicalization/tree/master/testdata),
licensed under Apache-2.0.
