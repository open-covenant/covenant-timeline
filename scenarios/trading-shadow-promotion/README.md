# Trading Shadow Promotion

A strategy progresses through historical replay, deterministic backtest,
forward paper execution, and read-only live shadow operation.

Each environment has a different subject identity, credential boundary, event
stream, and attestation type. Promotion requires a versioned decision backed by
execution, risk, reconciliation, incident, and independent-review evidence.

The scenario fails if:

- backtest evidence uses information observed after decision time;
- a configuration flag relabels a simulation as live evidence;
- profit overrides exposure, oracle, margin, or kill-switch policy;
- a score grants uncapped authority.

No order or custody adapter is exercised in the pre-alpha scenario.
